# Telegram Forwarding Bot

A Telegram bot to forward unrestricted content from channels/groups to multiple destinations, with topic support and pinned message copying.

## Features
- **Admin Approval**: Users must request access. Admin can approve or revoke access.
- **Range Forwarding**: Forward specific ranges of messages using links.
- **Always Active**: Includes a web server to keep the bot alive on Render using services like cron-job.org.
- **Topic Support**: Can forward to specific topics in supergroups.
